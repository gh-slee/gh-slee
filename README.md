## 🚀 Open-Source Projects

### 🧭 [Agentic SDLC](https://github.com/gh-slee/agentic-sdlc)

A reusable framework for building software with AI coding agents while maintaining engineering standards.

- Structured development workflows, agent roles, and quality gates
- Consistent pull request standards and verification evidence
- Reusable across repositories, languages, and technology stacks

**Focus:** Developer Tooling · Agentic Engineering · Python · CI/CD

### 📊 [Wealth Ledger](https://github.com/gh-slee/wealth-ledger)

A self-hosted investment ledger designed to help you understand and manage your financial data without relying on a third-party portfolio dashboard.

- Import supported brokerage and Bitcoin transaction data
- Track portfolios, contributions, and investment history
- Generate financial reports and exports

**Stack:** React · TypeScript · Python · FastAPI · SQLite · Docker

### 📚 [KOReader Bridge](https://github.com/gh-slee/koreader-bridge)

Tools for migrating and managing KOReader setups across supported Kobo e-readers.

- Device migration with previews, backups, and recovery safeguards
- Preserve reading data, library files, and configurations
- Offline Python CLI and a macOS app in development

**Stack:** Python · SwiftUI · macOS

### 📖 [InkKit](https://github.com/gh-slee/inkkit)

An open-source macOS utility for managing compatible XTEINK e-readers.

- Edit CrossInk device settings through a native interface
- Back up and restore device configurations
- SD-card backup and migration utilities

**Stack:** SwiftUI · Python · macOS

*Some projects are in active development or pre-release. Check each repository for current capabilities, supported devices, and installation instructions.*
